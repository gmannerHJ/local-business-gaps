Methodology

Every number on this site is computed by code from the public Overture Maps release. Nothing is entered by hand. The pipeline is run by one person with AI agents; the code is in the repository. This site is not affiliated with or endorsed by the Overture Maps Foundation or its data providers.

Source

Overture Maps Foundation, overturemaps.org: the places theme for the counts and the divisions theme for city populations and boundaries. The data is GeoParquet on public cloud storage. It is queried in place with DuckDB over HTTP range requests, filtered by bounding box, so only the parts of the files that cover a city are read. Each page states the Overture release it was computed from.

Cities

The city list (200 cities) is generated from the Overture divisions theme by this rule:

Selection rule (all computed from Overture divisions, licence ODbL):
  1. Candidates: divisions with subtype 'locality', class 'city', a Wikidata id and
     population >= MIN_POPULATION.
  2. Boundary: the locality's own division_area polygon (land); if there is none, the land
     polygon of another division in the same country with the same Wikidata id (many large
     cities are modelled as a county or region). A polygon is rejected when it clearly does
     not correspond to the population figure: bounding box wider than MAX_SPAN_DEG, or
     population / bounding-box area outside [MIN_DENSITY, MAX_DENSITY] people per km2.
  3. If no polygon is accepted, the boundary is a circle around the division's point:
     10 km below 1 million people, 15 km from 1 to 5 million, 20 km above.
  4. Cities are taken in descending population. A city is skipped when its point lies in the
     bounding box of a larger selected city of the same country (boroughs, duplicates), or
     when its country already has MAX_PER_COUNTRY cities. Stop at TARGET cities.

Limits of this rule: population figures and boundaries are whatever the divisions theme holds, so some cities are represented by a wider administrative area and some well-known cities are missing because the source gives them no population, no class or no Wikidata id. Boundary polygons are simplified to about 20 m.

What is counted

A place is counted when it lies inside the city boundary, has confidence >= 0.5 and is not marked permanently_closed.

Overture documents confidence as "a value between 0 and 1 representing the likelihood that the place exists" and gives no recommended cutoff. 0.5 keeps the records rated more likely to exist than not. Overture also notes that the score is not calibrated to be strictly comparable across data providers, so the threshold does not behave the same way everywhere. Each city page reports how many places fell below the threshold. The totals move with the cutoff, so read every count as "at confidence 0.5 or higher".

"No website listed" means the websites field of the record is missing, empty or holds only blank entries. Some records carry a list whose only entry is an empty string; those are counted as no website listed, and the same rule is applied to phone numbers and social links. It does not prove the business has no website. Some listed websites are social media pages or no longer work. Categories are Overture's basic_category labels; groups are the first level of taxonomy.hierarchy. The places theme includes non-commercial places such as parks, schools and government offices; the group table on each city page shows them.

The query

Per city, the rows inside the boundary are selected into a temporary in-memory table with only the columns below. No names, addresses, phone numbers or coordinates are selected, and no per-place rows are written anywhere.

CREATE OR REPLACE TEMP TABLE city_places AS
SELECT
    confidence,
    operating_status,
    basic_category,
    taxonomy.hierarchy[1]              AS category_group,
    trim(coalesce(array_to_string(websites, ''), '')) <> '' AS has_website,
    trim(coalesce(array_to_string(phones, ''), ''))   <> '' AS has_phone,
    trim(coalesce(array_to_string(socials, ''), ''))  <> '' AS has_social,
    coalesce(len(websites), 0) > 0                          AS website_list_present
FROM read_parquet('{places}')
WHERE bbox.xmin BETWEEN $xmin AND $xmax
  AND bbox.ymin BETWEEN $ymin AND $ymax
  AND ST_Contains(ST_GeomFromWKB($boundary), ST_Point(ST_X(geometry), ST_Y(geometry)))

Totals:

SELECT
    count(*) FILTER (WHERE confidence >= 0.5 AND operating_status IS DISTINCT FROM 'permanently_closed')                                        AS places,
    count(*) FILTER (WHERE confidence >= 0.5 AND operating_status IS DISTINCT FROM 'permanently_closed' AND has_website)                        AS with_website,
    count(*) FILTER (WHERE confidence >= 0.5 AND operating_status IS DISTINCT FROM 'permanently_closed' AND NOT has_website)                    AS without_website,
    count(*) FILTER (WHERE confidence >= 0.5 AND operating_status IS DISTINCT FROM 'permanently_closed' AND NOT has_website AND has_phone)      AS without_website_with_phone,
    count(*) FILTER (WHERE confidence >= 0.5 AND operating_status IS DISTINCT FROM 'permanently_closed' AND NOT has_website AND has_social)     AS without_website_with_social,
    count(*) FILTER (WHERE confidence >= 0.5 AND operating_status IS DISTINCT FROM 'permanently_closed' AND NOT has_website AND website_list_present) AS blank_website_entries,
    count(*) FILTER (WHERE confidence < 0.5 OR confidence IS NULL) AS below_confidence,
    count(*) FILTER (WHERE confidence >= 0.5
                     AND operating_status = 'permanently_closed')        AS permanently_closed,
    count(*)                                                              AS in_boundary_all
FROM city_places

Category and group splits (col is basic_category with LIMIT 10, or category_group):

SELECT {col} AS category,
       count(*)                                AS places,
       count(*) FILTER (WHERE has_website)     AS with_website,
       count(*) FILTER (WHERE NOT has_website) AS without_website
FROM city_places
WHERE confidence >= 0.5 AND operating_status IS DISTINCT FROM 'permanently_closed' AND {col} IS NOT NULL
GROUP BY 1 ORDER BY places DESC, category {limit}

Updates
